# Landing Page

A modern, responsive landing page built using **Vite, React, and TypeScript**, styled with **Tailwind CSS** and **shadcn/ui** components.

This project is intended to be used as a **generic landing page** for a product, service, or brand, and can be easily customized or extended.

---

## Tech Stack

- Vite – Fast frontend tooling
- React – UI library
- TypeScript – Type safety
- Tailwind CSS – Utility-first styling
- shadcn/ui – Prebuilt, accessible UI components

---

## Features

- Responsive layout (mobile-first)
- Clean, modern UI
- Component-based structure
- Fast development and build times
- Easy to customize content and sections

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Aditi960/Landing_page.git
cd my-digital-hub
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

The app will be available at:
```
http://localhost:5173
```

---

## Build for Production

```bash
npm run build
```
